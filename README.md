# WHMIS Warm Course Prototype

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000

## What is included
- Course home
- Module 0 through Module 14
- Bonus summary
- Warm, low-saturation visual theme on white background
- Batch 1 OpenMAIC click-to-reveal activities embedded in Modules 2–7, 12, 13 and Bonus
- Custom simple quiz interactions for Modules 1, 8, 10 and 11
- Custom multiple-select PPE quiz for Module 9
- Custom clean 5-question Module 14 knowledge check
- 20-question randomized prototype final assessment with 80% pass logic

## Design rule
Website content provides the visual richness: titles, text, cards, picture/text blocks and takeaways. Interactive patterns stay simple and consistent.
